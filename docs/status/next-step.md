Updated 2026-11-10. Build sessions read this file, so it says what is true now.

## Where ARI is
ARI runs live on iMessage (replies in seconds, catch-up after sleep), with GET DONE,
Calendar, Gmail (read only), Mac control, the hub (Today, Content, Inside ARI), and
the desktop pets. It reviews itself at 8:00 and 21:00, proposes builds, builds the
approved ones nightly in a Claude session, and ships on "ship it". Every building
day becomes a story in the content library. The watchdog texts every failure.

## Immediate next implementation
Close the self-improvement loop: seven days after a release, the review reads the
build log and tool use and says whether what shipped got used. Unused builds weigh
against similar proposals; used ones raise their priority. A feature that couldn't
be used (blocked on a setup step) is reported as blocked, not unused.
